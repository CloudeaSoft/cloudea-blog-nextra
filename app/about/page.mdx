## 关于我

刚大四毕业。日常多半泡在代码里，也会打打游戏、涂两笔画、在琴键上瞎摸——兴趣不少，但大多只是开了个头。

技术栈偏 C# 与 JS，C++、Java 也碰过一点。毕业设计做了 [Cloudea Platform](https://github.com/CloudeaSoft/cloudea-platform) 论坛，前后端和文档都自己啃，项目还在慢慢推进。

游戏里待得最久的是 Osu! Mania：主玩 6K，喜欢写谱，最近在练 8K。Terraria、Warframe，以及一些二刺螈手游也会开一开。字幕方面偶尔会焊化（黑奴嵌字）。

## 关于本站

本博客基于 [Next.js](https://nextjs.org) 与 [Nextra](https://nextra.site) 编写，静态导出后通过 GitHub Pages 部署，也可按需切换到 Cloudflare Workers 等服务端部署。站点从早期的 Hexo + Redefine 主题迁出，用来继续分享平时学习、开发时积累的经验，以及一些日常生活。
