## 关于本站

本博客基于 [Nextra](https://nextra.site) 编写，静态导出后通过 GitHub Pages 部署，后端代理使用 Cloudflare Workers 部署，评论系统 Waline 使用 Vercel 部署。

旧博客为 [Hexo + Redefine 主题](https://cloudeasoft.github.io/cloudea-blog/), 现已全部迁出。

## 友链交换

欢迎交换友链。已交换的站点见 [Friends](/friends)。

<Callout type="important">
  请先将本站加入你的友链，确认可以访问后，再在下方评论区按格式留言。未先添加本站的申请不会处理。
</Callout>

### 本站信息

把下面这段 YAML 加到你的友链列表里：

```yaml
name: 清露茶坊
link: https://blog.cloudea.work
description: 雨落生烟，云过留露
avatar: https://blog.cloudea.work/images/avatar.jpg
```

### 申请留言格式

添加完成后，在下方评论中粘贴并填写你的站点信息（字段与 `friends.yml` 一致）：

```yaml
name: 你的站点名
link: https://your.site
description: 一句话简介
avatar: https://your.site/avatar.png
```
